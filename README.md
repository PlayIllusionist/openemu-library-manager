## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **ROM Metadata** | Edit titles, artwork and release info for any library entry |
| **Save Manager** | Browse, export and restore save states per game |
| **Core Assignment** | Set preferred emulation core per system or individual title |
| **Library Sync** | Scan and import new ROMs with automatic metadata fetching |
